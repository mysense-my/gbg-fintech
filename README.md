# GBG for Fintech: landing page concept

A one-page concept for GBG APAC's fintech audience, prepared by MYSense for a pitch (Nov 2026).
Static HTML, CSS and JS: `index.html` plus `img/` and `fonts/`. No build step needed to view it.

Preview locally:

```bash
python3 -m http.server 8793
```

then open http://localhost:8793.

Notes:
- All facts, quotes, customer logos and blog posts come from gbg.com/apac. The "Get a demo" buttons link to GBG's own demo page.
- The demo and newsletter forms are not connected to a backend.
- Mint Grotesk is GBG's licensed typeface; it is included only to show this concept in GBG's brand.
- The page is marked `noindex`.
